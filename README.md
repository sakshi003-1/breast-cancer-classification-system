# Breast Cancer Project

## Structure

```text
breast_cancer_project/
├── train.py
├── app.py
├── requirements.txt
├── README.md
└── results/
```

`train.py` is intended to train the model and create `model.pkl`, `scaler.pkl`, and `features.pkl`. These generated artifacts are not included in the initial project structure. Store charts and metrics in `results/`.
